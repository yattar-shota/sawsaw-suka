# sawsaw-suka

フィリピンの伝統的な手遊びゲーム「Sawsaw-suka」をブラウザ上で遊べるようにしたゲームです。

[こちらから遊べます。](https://yattar-shota.github.io/sawsaw-suka/)

---

## ゲームの概要
「Sawsaw-suka（直訳：酢に浸す）」は、フィリピンの伝統的な手遊びゲームです。一人が広げた手のひらを、もう一人が「sawsaw suka, mahuli taya!(お酢に浸して、捕まったら負け!)」と唱えながら人差し指でつつきます。「taya!」の合図で手のひらを閉じた際、指が捕まってしまったら負けとなります。
-一度クリアするとhard modeが解放され手がランダムなタイミングで閉じるようになり、手が閉じるまでの時間が短くなります。
---

## 遊び方
-Dipを押して指を手のひらに浸しpullで戻すを繰り返して掛け声を始める。
-掛け声がtaya!に達すると手が閉じるのでpullを押して逃げる。
